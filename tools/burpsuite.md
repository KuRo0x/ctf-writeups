# Burp Suite

## Purpose
Web application security testing platform used for intercepting, modifying, and replaying HTTP/HTTPS requests.

---

## ⚡ Common Features

```
- Proxy: Intercept and modify HTTP requests
- Repeater: Replay and modify requests manually
- Intruder: Automated attack tool for fuzzing
- Scanner: Passive/active vulnerability scanning
- Decoder: Encode/decode data
```

---

## 🎯 Used For

- Web request interception
- SQL injection testing
- Parameter tampering
- Authentication bypass testing
- XSS testing
